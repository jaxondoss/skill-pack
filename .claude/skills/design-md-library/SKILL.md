# DESIGN.md library (awesome-design-md)

Upstream: [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see `LICENSE`).
`design-md/<site>/DESIGN.md` holds each analysis; `README.md` is the upstream index with descriptions.

How to use:

1. List `design-md/` and pick one to three sites whose feel matches the brief.
2. Read their `DESIGN.md` and take the system: palette roles, type scale, spacing rhythm, radius, component patterns.
3. Adapt it to the project's own tokens and content. Use these as reference for a design language, never to copy a
   brand's logo, name, wordmark or trade dress, and never to make a page that passes as that company.
